# Penny Surface Analyzer in MATLAB

This project analyzes MATLAB's built-in `penny.mat` example dataset.

The project loads a 3D surface matrix of a US penny, calculates basic surface statistics, and generates visual plots such as:

- 3D surface plot
- 2D height map
- Gradient magnitude map
- Height distribution histogram

## Source

This project is based on MATLAB's official example dataset `penny.mat`.
